Overview

FTIR Vol-Cal is an open-source spectral fitting tool for calculating dissolved H2O (wt%) and CO2 (ppm) concentrations in volcanic glass and melt inclusion FTIR spectra. It replaces a suite of Excel spreadsheet templates with a single, reproducible workflow and combines multiple mathematical fitting approaches. It is coded in Python and published online for easier usability. You may also download the source code and add other functions you need.

1. Input Files

1.1 Transmission Spectrum (required)

Upload a transmission spectrum from FTIR measurement. The range of wavenumbers is usually around 300–6000 cm−1. FTIR Vol-Cal does not currently consider water-saturated species and therefore does not fit OH (@4500 cm−1) or H2Om (@5200 cm−1) — this will be updated soon. To fit the H2Ot peak, the range used is 2200–4000 cm−1; for the carbonate doublet, it uses 1200–2200 cm−1.

1.2 Reflectance Spectrum (optional)

You may upload a reflectance spectrum to calculate glass wafer thickness automatically. If you don’t have one, you can enter the thickness measured by other methods (micrometer, optical microscope, etc.) manually.

1.3 Glass Composition (wt%)

Glass composition affects density calculations, so detailed major element information is required. A basaltic composition of Hawaiian melt inclusion is shown as an example.

1.4 Olivine Mg#

Olivine Mg# affects the calculation of refractive index. Enter the host olivine Fo number. Currently only olivine refractive index is supported; other mineral phases will be added in future updates.

1.5 Advanced Parameters

We use Fe3+/Fetotal = 0.15 as default. You can change this value manually. We convert FeOt to Fe2O3 and FeO based on this ratio for a more precise glass density. You can also enter custom epsilon values (molar absorptivity) for OH, H2Omol, and CO3. These are used in the Beer-Lambert law to calculate H2O and CO2 concentrations.

1.6 Batch Processing

You can batch upload FTIR transmission spectra using the same or different reflectance spectra and calculating parameters (compositions, Mg#, model choice). Transmission and reflectance spectra should use the same sample file name. You can also upload per-sample parameters via a CSV template.

2.1 Thickness Determination

Mode A — Manual Fringe Counts

Input your counts of interference fringes between wavenumbers.

d = N / (2 × n × (wnhigh − wnlow))

where n is the glass refractive index (a function of olivine Fo#) and N is the number of fringes between wnhigh and wnlow.

Mode B — Direct Input

Direct thickness measurement of your wafers.

Mode C — Auto-Detect from Reflectance Spectrum

Automatically calculated from reflectance spectra:

  1. Extract the 1800–3000 cm−1 range (clean, absorption-free window)
  2. Savitzky-Golay smoothing to remove noise
  3. Detect maxima and minima independently
  4. Select the longest consecutive sub-sequence of consistent fringe intervals (within 20% of the sub-sequence median), automatically rejecting false peaks from noise or baseline drift
  5. Thickness calculated from selected peaks, averaging maxima-derived and minima-derived values
  6. Uncertainty = standard deviation of per-interval thicknesses

2.2 H2O Peak Fitting

H2O peak height is determined by linear baseline correction:

Baseline

Linear baseline anchors are determined from two regions: low anchor (2200–2400 cm−1) and high anchor (3700–4000 cm−1). We use the mean wavenumber and mean absorbance in each anchor region to define the baseline. This reduces noise sensitivity compared to picking a single minimum point. You can also change or select the baseline in our interactive window.

H2O Iteration

It’s a chicken-and-egg problem: you need H2O to calculate the density, but you also need density to measure H2O. We first assume H2O = 0, calculate H2O from the spectrum, add the new value back into the composition, and repeat until |new − old| < 0.001 wt%. This typically converges within 2–3 steps.

Uncertainty

H2O uncertainty is propagated from two sources, combined in quadrature:

  1. Thickness uncertainty — relative thickness error propagates directly via Beer-Lambert.
  2. Baseline anchor variation — the low anchor region is divided into overlapping sub-windows (~67 cm−1 wide); each produces a slightly different baseline and peak height. The standard deviation of these peak heights quantifies baseline uncertainty.

Concentration

H2O concentration is calculated following the Beer-Lambert law.

2.3 CO2 Doublet Fitting

Preprocessing: The input spectrum is normalized to 100 μm thickness. Fitted coefficients correspond to a standard path length, and concentration formulas use 100 instead of the actual thickness.

2.3.1 Simple lstsq Model

The same fitting method as the original Excel template, using least squares to fit the carbonate doublet. You can find the original Excel template in the GitHub repository.

y = offset + cbkg × E + c1630 × F + cCO3 × G + cst × H
  • E = devolatilized glass reference spectrum (WOK162, background only)
  • F = 1630 cm−1 molecular H2O peak reference
  • G = CO32− doublet reference
  • H = linear slope correction
  • offset = constant baseline shift
  • cbkg, c1630, cCO3, cst = fitted coefficients

Fitting range: 1350–1800 cm−1 (116 points)
Limitation: The E background is from one specific composition (WOK162); it works for similar compositions but fit quality degrades for very different compositions.

2.3.2 lstsq with Shifted Peak Position

The carbonate doublet peaks (~1430 and ~1515 cm−1) may shift their positions independently due to different cation environments (Na+, Ca2+, Mg2+). The Simple lstsq model locks the doublet as a single fixed reference, so it cannot capture these shifts.

This model replaces the fixed doublet with two independent Gaussian peaks, each with an additional derivative term that allows the peak position to shift independently. The background and baseline treatment remain the same as the Simple lstsq model. After fitting, the independent shift of each peak is recovered from the ratio of derivative to amplitude coefficients.

Fitting range: 1350–1800 cm−1
Peak shift positions are reported for fitting quality assessment.

2.3.3 PCA Baseline

A single devolatilized glass reference (WOK162) is not sufficient to capture the baseline shape for all compositions. Following Shi et al. (2024), we use pre-computed PCA components trained on 57 devolatilized glass spectra (basalt–andesite, SiO2 = 43–60%) from the PyIRoGlass database (5 baseline components: 1 mean + 4 principal components). This provides a more flexible baseline that adapts to different compositions, particularly in the 1250–1350 cm−1 range where Si–O absorption varies significantly.

  • 14 parameters solved with bounded linear least squares (unlike Shi et al. 2024, which uses MCMC to fit the doublet).
  • Two independent Gaussians + Taylor-expanded derivative terms for independent peak shift estimation.
  • Fitting range: 1250–2200 cm−1 (wider range to capture Si–O signals, similar to Shi et al. 2024).

2.4 Fringe Correction

Interference fringes may affect carbonate doublet fitting in relatively thin wafers, resulting in overestimation of CO2 concentration. We include an optional fringe correction to minimize the impact.

  • Periodic fringes are detected in the 2200–2800 cm−1 region (excluding 2280–2400 cm−1 for atmospheric CO2).
  • Detection criteria: coefficient of variation of half-spacings < 0.35 and amplitude > 0.003.
  • Sin/cos basis functions (fundamental + 2nd harmonic) are added to the fitting model, so fringes are removed jointly with CO3 fitting.
This method may inadvertently subtract part of the carbonate signal if fringes are not perfectly periodic. We recommend manually assessing fringe-corrected results for spectra with strong interference fringes. You can choose “auto”, “always”, or “off”. We recommend turning off the correction if your spectra are fringe-free. Fringe correction will be updated if we find better solutions.

2.5 Quality Estimation

We provide a quality flag for each CO3 fit as a reference. We recommend manually checking the results, especially for imperfect spectra (with fringes, host contamination, or other unexpected features).

Quality is estimated based on R2, peak shift, and signal-to-noise ratio (SNR):

FlagCriteria
GOODHigh R2, high SNR, low peak shift
FAIRIntermediate R2
POORLow R2
NEGATIVENo carbonate doublet detected (cCO3 ≤ 0; devolatilized glass or CO2 below noise level)
SUSPECT|peak shift| > 15 cm−1 (likely not carbonate; may be fringes or contamination — manual check required)

3. Output

3.1 Physical Properties

Thickness, density, and refractive index of the olivine host.

3.2 H2O Peak

H2O total peak height is read at a fixed position of 3550 cm−1 (interpolated), rather than at the maximum absorbance position. This provides consistency across samples.

3.3 Carbonate Fit Results

Fitting model used; carbonate doublet mean absorbance and uncertainty; R2; fitting quality flag; and doublet peak shift.

3.4 Concentrations

Calculated from the Beer-Lambert law. Currently only considers total H2O (undersaturated; does not fit the 4500 and 5200 cm−1 water peaks).

  • H2O uncertainty: from baseline anchor variation and thickness uncertainty, combined in quadrature.
  • CO2 uncertainty: from (1) fitting noise (residual RMS of model vs. data) and (2) shift sensitivity (variation in CO3 absorbance when peak position is swept ±20 cm−1), combined in quadrature.
  • CO2 detection limit: 3 × residual RMS, converted to ppm via Beer-Lambert. If SNR < 3, CO2 is marked as BDL (below detection limit).
  • H2O iteration: density and H2O are solved iteratively (see Section 2.2).

3.5 Diagnostic Figures

  • Carbonate doublet: (1) fitting results vs. sample data with components; (2) carbonate doublet after baseline subtraction; (3) residuals.
  • H2O total: (1) raw spectrum with linear baseline and anchor regions; (2) peak height after baseline subtraction.

3.6 Interactive Window

  • Carbonate doublet: interactive chart where you can zoom in/out and download the fitting data.
  • H2O peak: check the default fitting result, or select custom points/regions for the linear baseline.
  • Batch fitting: browse through all fitted samples via a dropdown menu and inspect fitting quality before downloading.

3.7 Download

You can download: (1) detailed model values at each wavenumber (CSV); (2) calculated concentrations; (3) all diagnostic figures.
